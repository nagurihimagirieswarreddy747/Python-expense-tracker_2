# Python Expense Tracker

A Python based Expense Tracker using JSON file handling.

## Features
- Add Expense
- View Expenses
- Total, Highest, Lowest Expense
- Category Total & Search
- Delete & Update Expense
- Data saved in expenses.json file

## How to Run
1. Python must be installed
2. Run the file using: python main.py
3. Select an option from the menu to use it
